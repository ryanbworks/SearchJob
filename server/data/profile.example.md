# Perfil do candidato (exemplo)

Copie este arquivo para `data/profile.md` e escreva com as suas informações.
A IA usa este texto para dar nota às vagas e redigir respostas. Ele fica só no seu servidor.

## Objetivo
Primeira oportunidade em Suporte Técnico / Help Desk (N1), presencial, híbrido ou remoto.

## Formação
- Graduação em andamento na área de TI (1º período)

## Conhecimentos
- Windows 10/11: instalação, formatação, drivers, contas de usuário
- Microsoft Office / Microsoft 365
- Montagem e manutenção de computadores
- Redes básicas: IP, DNS, DHCP, Wi-Fi
- Linux básico e virtualização (homelab com Proxmox)
- Noções de Python e automação

## Projetos
- SearchJob: sistema próprio que coleta e analisa vagas com IA local (Python, FastAPI, SQLite, Docker)

## Diferenciais
- Boa comunicação e paciência no atendimento
- Aprende rápido e gosta de documentar soluções

## Preferências
- Cidade: (sua cidade / UF)
- Pretensão salarial: (valor)
- Disponibilidade: imediata
